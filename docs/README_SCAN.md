# Prism Lab 스캔 — 입력 없는 단일 경로

2026-09-24 기준. 사람이 칠 게 없다. 더블클릭 하나면 끝난다.

## 쓰는 법

```
SCAN.bat            더블클릭 — 바탕화면 최근 촬영 폴더를 자동으로 잡는다
SCAN.bat <폴더>     또는 사진 폴더를 이 파일 위로 드래그
```

서버가 꺼져 있으면 알아서 켜고 기다린다. 결과는 `<폴더>\_scan\` 에 나온다.

| 파일 | 내용 |
|---|---|
| `points.ply` | 색 있는 점군 — **지금 가장 쓸 만한 결과물** |
| `mesh.ply` / `mesh.stl` | Poisson 메쉬 |
| `preview.png` | 4방향 미리보기 |
| `result.json` | 경로·점수·소요시간 |

## UI 연동

```
python scan_run.py <폴더> --json
```

stdout 에 한 줄씩 JSON 이 나온다. 화면의 실행 단계 1·2·3 과 `stage` 가 그대로 맞는다.

```json
{"stage": 1, "state": "running", "pct": 0,   "msg": "장비·서버 확인"}
{"stage": 1, "state": "done",    "pct": 100, "images": 133, "device": "cuda"}
{"stage": 2, "state": "running", "pct": 70,  "msg": "물체만 남기는 중"}
{"stage": 2, "state": "done",    "ply": "...", "stl": "...", "n_triangles": 132733}
{"stage": 3, "state": "skipped", "msg": "분광기 미연결 — 재질 분석 건너뜀"}
```

`state` 는 `running` / `done` / `error` / `skipped`. 오류면 종료 코드 1.
3단계(재질 분석)는 분광기 취득 코드가 없어서 자리만 잡아뒀다.

## 왜 아무것도 안 묻는가

시료는 항상 한 개고 턴테이블 위에 있다. 그러면 사람이 정할 게 없다.

- **SAM 프롬프트** — 후보 3개를 12장 표본에 돌려보고 마스크 확보율·크기로 고른다.
  전체 프레임에 돌리면 안 된다. 본 마스킹은 서버가 어차피 다시 하고,
  133장이면 그것만 125초다.
- **필터·정리** — 전부 데이터에서 정한다.

예전에는 프롬프트를 사람이 쳤는데 그게 품질을 좌우했고(같은 사진에서 물체 덮음률
45.2% ~ 91.6%), `|` 가 들어가면 배치 파일이 죽었다.

## 정리가 하는 일 (`object_clean.py`)

서버는 SAM 마스크가 잡히면 거리 필터를 스스로 풀어버린다(`SAM_DIST_PCT=100`).
그래서 배경이 통째로 들어온다. 실측 0831_2058 / 133장:

| 단계 | 점 | 대각선 | 중심거리 최대 |
|---|---|---|---|
| 서버 출력 | 1,745,124 | 7.50 | 4.06 |
| 군집 분리 | 1,745,124 | 1.63 | — |
| 후광 제거 | 873,458 | 0.465 | — |
| 잡음 제거 | 840,497 | 0.465 | 0.22 |

퍼센타일 필터(`--dist 92`)로는 안 잡힌다 — 멀리 뭉친 배경은 어느 퍼센타일에서도
살아남아 최대가 4.06 이었다. 밀도 군집은 거리가 아니라 연결성을 보므로 잡힌다.

`remove_halo` 는 물체에 붙어 있는 뿌연 후광을 국소 밀도로 깎는다. 후광은 물체와
이어져 있어서 군집으로는 못 뗀다.

⚠ 얇은 물체(판·철사)는 표면 자체가 성기다. `--keep-pct` 를 올려라(기본 50).

## 아직 안 되는 것

**메쉬가 굽은 껍데기로 나온다.** 점군을 다 정리하고 법선을 바깥으로 강제해도
같았다. 원인은 VGGT 깊이맵의 체계적 왜곡이다 — 프레임 *내부* 오차가 TSDF 절단
거리의 3.13배라서 표면이 한 곳으로 모이지 않는다(2026-09-11 측정). 후처리로는
못 편다.

성긴 부위가 밀도 트림에 걸려 잘리기도 한다(0831_2139 에서 메쉬 Z 가 점군 1.014
대비 0.924 에서 끊겼다 — 팬 그릴 부분).

**치수를 재거나 3D 프린트할 거면 정밀 경로를 써라.**

```
python scan_run.py <폴더> --precise
```

VGGT 결과를 먼저 내주고 이어서 COLMAP 덴스 MVS 까지 돌린다. 수십 분 더 걸린다.

## 물체에 따라 크게 다르다

같은 파이프라인, 같은 설정인데:

- `0831_2139` 손선풍기 119장 → 9.6분, 127만점. 손잡이·헤드·날개까지 제대로 나옴
- `0831_2058` 모터 133장 → 점군은 정리되지만 형상이 안장처럼 휨

어둡고 금속 광택이 있는 작은 물체가 VGGT 에 불리하다. 그런 시료는 `--precise`.

## 파일

| 파일 | 역할 |
|---|---|
| `SCAN.bat` | 더블클릭 진입점 |
| `scan_run.py` | 본체. 입력 없음, JSON 진행률 |
| `object_clean.py` | 군집·후광·잡음 정리 |
| `_newest_folder.py` | 바탕화면 최근 촬영 폴더 찾기 |
| `_wait_server.py` | 서버 기동 대기 |

기존 진입점(`SCAN-3D.bat`, `VGGT-Test.bat`)은 건드리지 않았다. 원본 `vggt_dev`
폴더도 그대로다.
