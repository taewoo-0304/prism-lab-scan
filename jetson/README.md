# jetson — 촬영 쪽

젯슨은 **촬영과 전송만** 한다. 계산은 전부 PC(노트북)가 한다. 젯슨 로컬 폴백은 없다.

시스템 파이썬으로 실행한다(가상환경 불필요). `cv2`, `requests` 가 필요하다.

| 파일 | 하는 일 |
|---|---|
| `scan.py` | 통합 진입점 — 촬영 → PC 로 전송 → 결과 표시 |
| `rig.py` | 촬영 시퀀스(모터 각도·순서) |
| `capture.py` | 촬영만 단독으로 |
| `offload.py` | 이미 찍어둔 폴더를 PC 로 보내 재계산 |
| `remove_bg.py` | 배경 제거 (rembg) |

이 다섯 파일은 서로만 import 한다. 폴더째 젯슨에 복사하면 된다.

## PC 찾기

`scan.py` 는 같은 네트워크의 PC 를 자동으로 찾는다(IP 입력 불필요). 포트는 5000.
안 되면:

1. PC 에서 `VGGT-Server.bat` 이 떠 있는지
2. 같은 공유기에 붙어 있는지
3. PC 의 Windows 방화벽에서 5000 포트 인바운드 허용

⚠ PC 에 공인 IP 가 직접 붙어 있으면 5000 포트를 열지 마라. 서버가 `0.0.0.0` 으로
바인드하므로 인터넷에 그대로 노출된다. 젯슨과 PC 를 같은 사설망(공유기)이나
VPN 으로 묶어라. PC 혼자 테스트할 때는 `set VGGT_HOST=127.0.0.1` 로 로컬에만 연다.
